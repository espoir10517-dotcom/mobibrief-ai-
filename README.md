# MobiBrief AI

**AI가 골라주는 이번 주 핵심 뉴스** — 자동차보험 · 모빌리티 · 보험 · AI 기술 분야별 TOP 10을 매주 월요일 아침 휴대폰으로.

> 현재 운영 방식: **AI 없이 실제 뉴스 자동 선정** (월 운영비 0원)
> 매일 06:30 국내외 뉴스를 수집해 쌓아 두고(무료), **매주 월요일 06:30** 지난 7일치 뉴스에서 분야별 TOP 10을 골라 앱에 반영합니다. AI 키를 등록하면 AI가 편집 기준(`config/editorial.md`)으로 고르고 요약합니다.

---

## 한눈에 보는 구조

```
 ┌── 매일 수집 · 매주 월요일 발행 (자동) ──┐        ┌──── 휴대폰 ────┐
 │ GitHub Actions (무료 자동 실행)           │        │                 │
 │  1. 뉴스 수집  Google News RSS · 언론사 RSS │  JSON  │  MobiBrief AI   │
 │  2. 자동 선정  규칙 기반 (AI는 선택 사항)   │ ─────▶ │  (PWA 앱)       │
 │  3. TOP 5 선정 · 핵심 이슈 · 트렌드 계산    │  파일  │  홈 화면 아이콘  │
 │  4. 알림 발송  Web Push / 텔레그램          │        │                 │
 └──────────────────────────────────────────┘        └─────────────────┘
```

- **서버·데이터베이스가 없습니다.** 하루 한 번 자동 작업이 결과를 JSON 파일로 만들고, 앱은 그 파일을 읽기만 합니다. 그래서 운영비가 거의 들지 않고 고장 날 곳이 적습니다.
- **사용자 행동은 AI를 한 번도 부르지 않습니다.** 검색·MY NEWS·필터·즐겨찾기는 모두 이미 수집된 뉴스 안에서 휴대폰이 직접 골라 보여줍니다. 앱 코드에는 AI API 키도, AI 호출 코드도 없으며 앞으로도 넣지 않습니다. AI는 하루 한 번 자동 작업에서만 실행됩니다.
- **사용자가 몇 명이든 AI 비용은 같습니다.** AI 분석은 일주일에 한 번만 실행되고, 100명이든 300명이든 모두 같은 결과 파일을 봅니다. 접속할 때마다 AI를 부르는 구조가 아닙니다.
- **API Key는 GitHub 비밀값(Secrets)에만 저장**되고 앱 코드에는 들어가지 않습니다.
- **즐겨찾기·관심 키워드·설정은 휴대폰 안에만** 저장됩니다. 외부 서버나 AI로 보내지 않습니다.
- 뉴스 수집 · AI 분석 · 알림은 각각 독립 모듈로 만들어 서비스를 바꾸기 쉽게 합니다.

### 왜 이 서비스들을 쓰나요?

| 필요한 것 | 왜 필요한가 | 선택 | 비용 |
|---|---|---|---|
| 앱 호스팅 | 휴대폰에서 접속할 HTTPS 주소 (PWA 설치·알림에 HTTPS 필수) | Cloudflare Pages 또는 GitHub Pages | 무료 |
| 스케줄러 | 매일 수집, 매주 월요일 선정·발행 | GitHub Actions | 무료 |
| 뉴스 검색 | 국내·해외, 한국어·영어 최신 기사 | Google News RSS(한/영) + 국내 언론사 공식 RSS 21곳 | 무료 |
| AI (선택) | 요약·분석을 원할 때만 | Claude API — 현재 미사용 | 현재 0원 |
| 데이터 저장 | 과거 기사 검색·트렌드 | 저장소 안의 JSON 파일 (별도 DB 불필요) | 무료 |
| 알림 | 아침 브리핑·중요 뉴스 | Web Push (+ iPhone 대안: 텔레그램 봇) | 무료 |
| 알림 수신자 목록 | 여러 사용자의 알림 구독 정보 보관 (Phase 5) | Cloudflare Workers + KV | 무료 |

기사 **전문은 저장하지 않습니다.** 제목·언론사·발행시각·링크·검색 결과 설명문 등 허용된 메타데이터만 저장하고, 원문은 링크로 연결합니다.

## 1. 프로그램 실행 방법 (PC)

**준비물:** Node.js 20 이상 (https://nodejs.org 에서 LTS 버전 설치). 추가로 설치할 패키지는 없습니다.

```bash
cd mobibrief-ai
npm start
```

화면에 나오는 `http://localhost:5173` 을 브라우저에서 열면 됩니다. 종료는 `Ctrl + C`.

그 밖의 명령:

| 명령 | 하는 일 |
|---|---|
| `npm test` | 화면 데이터·TOP 5·점수·트렌드·뉴스 수집기 자동 점검 |
| `npm run collect` | 지금 바로 뉴스 수집 (네이버 키가 `.env`에 있으면 네이버도 포함) |
| `npm run build:demo` | 가상 기사(`scripts/demo/articles.mjs`)와 가중치(`config/scoring.json`)로 Demo 데이터 다시 생성 |
| `npm run build:preview` | 서버 없이 열리는 단일 파일 미리보기 `dist/preview.html` 생성 |

## 2. 휴대폰에서 접속하는 방법

**지금 바로 (같은 Wi-Fi):** `npm start` 를 실행하면 `휴대폰에서 열기 → http://192.168.x.x:5173` 주소가 표시됩니다. PC와 같은 Wi-Fi에 연결된 휴대폰 브라우저에 그 주소를 입력하세요.
- 회사 Wi-Fi는 기기 간 접속을 막아 두는 경우가 많습니다. 안 되면 집 Wi-Fi나 아래 배포 방법을 쓰세요.
- 이 방식은 화면 확인용입니다. 홈 화면 설치·알림은 HTTPS 주소(배포)가 필요합니다.

**최종 (어디서나):** 7번 "배포 방법"대로 올리면 `https://내이름.pages.dev` 같은 주소가 생기고, 집·회사·LTE 어디서나 접속됩니다.

## 3. 홈 화면에 앱처럼 설치하는 방법

배포된 HTTPS 주소에서 해야 합니다.

- **iPhone (Safari):** 하단 공유 버튼(□↑) → **홈 화면에 추가** → 추가
- **Android (Chrome):** 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**

설치 후에는 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 잠깐 끊겨도 마지막 뉴스를 볼 수 있습니다.

## 4. 필요한 API Key 설정 방법

Phase 1은 **키 없이** 동작합니다. 아래 키는 해당 Phase를 시작할 때 안내드리며, 그때 발급하면 됩니다.

| 키 | 언제 | 어디서 | 비용 |
|---|---|---|---|
| ~~네이버 검색 API~~ | 사용 안 함 | 2026년 NAVER API HUB 로 이관·유료화, 9월부터 검색 결과 저장·AI 입력 금지 약관 → 이 앱 구조와 맞지 않아 제외 | — |
| `ANTHROPIC_API_KEY` (선택) | AI 요약을 붙일 때만 | https://platform.claude.com → 결제수단 등록 → API Keys (Claude 구독과 별도 결제) | 사용량 과금 |
| `VAPID_*` | Phase 5 | 제공 스크립트로 자동 생성 | 무료 |
| `TELEGRAM_*` (선택) | Phase 5 | 텔레그램 @BotFather | 무료 |

키를 넣는 곳:
- **PC에서 시험할 때:** `.env.example` 을 복사해 `.env` 로 이름을 바꾸고 값 입력 (`.env` 는 업로드되지 않도록 막혀 있습니다)
- **자동 운영할 때:** GitHub 저장소 → Settings → Secrets and variables → Actions → **New repository secret** 에 같은 이름으로 등록

## 5. 뉴스 자동 업데이트 방식

### 지금 (AI 없이)

매일 06:30(한국시간) 뉴스를 수집해 `data/collected/` 에 쌓고, **매주 월요일 06:30** 에 지난 7일치를 모아 아래 순서로 발행합니다. (Actions 탭 → Run workflow 로 아무 때나 직접 발행할 수도 있습니다)

1. **수집** — 분야별 검색어로 Google News RSS(한국어·영어), 국내 언론사 공식 RSS(연합뉴스·경제지·보험/자동차/AI 전문지 등)에서 제목·요약문·링크·발행시각 수집
2. **정리** — 36시간 지난 기사·[포토]/[인사]/[부고]·주가 자동기사 제외, 같은 사건 보도를 하나의 이슈로 묶기
3. **분류** — `config/keywords.json` 키워드 사전으로 분야와 주요 키워드 판별 (제목 기준, 요약문은 보조)
4. **점수** — 중요도=보도한 언론사 수, 업무 연관도=분야 키워드(국내 기사 가산), 최신성=발행 시각, 영향도=정책·출시·투자 같은 변화 단어, 참신성=최근 3일 내 비슷한 기사 여부 → `config/scoring.json` 가중치로 종합
5. **선정** — 분야별 TOP 5 (이미 뽑힌 기사와 다른 주제 우선), 가장 많이 보도된 이슈 3개, 오늘의 핵심 키워드 5개
6. **반영** — `public/data/live/` 갱신 → 앱 주소에 자동 배포

앱에는 'AI' 대신 '자동 선정'·'중요도'로 표시되고, 상세 화면에서 함께 보도한 언론사 목록과 원문 링크를 볼 수 있습니다.

### AI 켜기 (키만 넣으면 자동 전환)

GitHub 저장소 → Settings → Secrets and variables → Actions → **New repository secret** 에 둘 중 하나를 등록하면, 다음 업데이트부터 AI 편집 방식으로 바뀝니다.

| 이름 | 어디서 발급 | 비고 |
|---|---|---|
| `ANTHROPIC_API_KEY` | https://platform.claude.com → API Keys | Claude (기본: Haiku 4.5) |
| `OPENAI_API_KEY` | https://platform.openai.com → API keys | GPT (기본: gpt-5.4-mini, `config/ai.json` 에서 변경) |

AI 방식에서 하는 일:
1. **평가** — 후보 100~200건 전부를 `config/editorial.md`(편집 기준: 손해보험사 자동차보험 부서 관점)로 읽고, 필요 없는 기사(스포츠·주가·MOU·해외 단신 등)는 걸러내며 5개 기준 점수와 이유를 매김
2. **선정** — 분야별 상위 후보에서 같은 사건은 하나만 남기고 TOP 5, 오늘 꼭 알아야 할 이슈 3개, 한 줄 브리핑 작성
3. **요약** — 선정된 기사만 3줄 요약·핵심 내용·왜 중요한가·보험 관점·앞으로 볼 것, 영어 기사 제목 번역
4. **근거 검증** — 기사(제목·요약문)에 없는 숫자가 들어간 문장은 자동 삭제. 제목만 있는 기사는 '내용 제한' 표시
5. **안전장치** — 한 번 실행에 AI 호출 25회·비용 $0.6 상한. 키 오류·잔액 부족 등으로 실패하면 규칙 방식으로 자동 대체 발행

예상 비용: 주 1회 실행에 약 $0.2~0.3 → **월 약 1천~2천 원** (사용자 수와 무관). 실제 사용량은 `public/data/live/briefing.json` 의 `ai` 항목과 Actions 실행 기록에 남습니다.

**편집 기준 바꾸기:** `config/editorial.md` 를 고치면 AI가 다음 업데이트부터 그 기준으로 고르고 요약합니다.

### (참고) AI 방식의 전체 흐름



1. **수집** — 위와 동일
2. **중복 정리** — 같은 사건을 여러 언론사가 보도하면 하나의 이슈로 묶고 대표 기사를 남김 (보도 매체 수는 신뢰도 참고값으로 표시)
3. **AI 평가** — 기사마다 중요도·업무 연관도·최신성·영향도·참신성을 100점 만점으로 평가 → 가중치로 종합점수 계산
4. **TOP 5 선정** — 점수순 + 주제 다양성(비슷한 기사 감점) 반영
5. **AI 요약·분석** — 선정된 20건만 3줄 요약·핵심 내용·왜 중요한가·보험 관점·앞으로 볼 것 작성. **수집된 기사 정보에만 근거**하도록 지시하고, 근거 없는 숫자·발표는 쓰지 않게 검증 단계를 둡니다.
6. **결과 저장** — `public/data/live/` 에 JSON 저장 → 앱이 자동으로 실데이터로 전환

평가 기준과 가중치는 `config/scoring.json` 에서 바꿀 수 있습니다.

**검색어·제외 규칙 바꾸기:** `config/sources.json` 에서 분야별 검색어(ko=한국어, en=영어), 제외할 제목 패턴(`[포토]`, `[인사]` 등), 제외할 출처를 고칠 수 있습니다. 분야별로 AI에 넘기는 후보는 최대 40건(`maxCandidatesPerCategory`)이라 검색어를 늘려도 AI 비용은 그대로입니다.

**수집 결과 확인:** GitHub 저장소 → `data/collected/` 폴더에 날짜별 파일이 쌓입니다. 실행 기록은 저장소 → **Actions** 탭 → '뉴스 수집'에서 볼 수 있고, **Run workflow** 버튼으로 바로 실행할 수도 있습니다.

참고: Google News RSS 는 개인·비상업적 이용을 전제로 제공됩니다. 이 앱은 제목·언론사·링크만 보여주고 원문으로 연결하는 방식으로 사용합니다.

## 6. 알림 설정 방법

앱의 **SETTINGS → 알림**에서 정기 브리핑(기본: 매주 월요일 오전 8시) 켜기/끄기·시간 변경, 중요 뉴스 알림과 기준 점수(80/85/90점+)를 정할 수 있습니다. 설정은 지금도 저장되며, **실제 발송은 Phase 5에서 연결**됩니다.

플랫폼별 제약:
- **Android:** Chrome에서 웹 알림이 잘 동작합니다.
- **iPhone:** iOS 16.4 이상 + **홈 화면에 추가한 앱**에서만 웹 알림을 받을 수 있습니다. Safari 탭에서는 불가합니다. 알림이 불안정하면 텔레그램 봇 알림을 대안으로 함께 제공합니다.
- 같은 이슈에 대한 중요 뉴스 알림은 한 번만 보내도록 중복 방지 기록을 남깁니다.

## 7. 배포 방법

**현재 운영 주소:** https://espoir10517-dotcom.github.io/mobibrief-ai-/

GitHub Pages 로 배포되어 있습니다. `public/` 폴더의 내용이 `gh-pages` 브랜치에 올라가면 1~2분 뒤 위 주소에 반영됩니다. (Phase 4부터는 매일 자동 작업이 이 과정을 대신합니다.)

### 다른 곳에 배포하고 싶을 때

**Cloudflare Pages (추천, 무료):**
1. https://github.com 계정 생성 → 새 저장소(Private 가능) 만들고 이 폴더 전체 업로드
2. https://dash.cloudflare.com → Workers & Pages → Create → Pages → **Connect to Git** → 저장소 선택
3. 빌드 설정: Framework preset `None`, Build command **비움**, Build output directory **`public`**
4. Deploy → `https://프로젝트명.pages.dev` 주소로 접속

이후 GitHub에 변경 사항이 올라가면(자동 수집 결과 포함) 몇 분 안에 자동 재배포됩니다.

| 알림 (Web Push / 텔레그램) | 0원 |
| AI (Claude 또는 GPT) | 키 등록 전 0원. 등록 후 **월 약 1천~2천 원** (주 1회, 후보 약 240건 평가 + 40여 건 요약) |

AI 비용 근거 (주 1회 기준): 분야별 후보 60건(총 240건)을 Haiku 4.5(입력 $1·출력 $5 / 100만 토큰)로 평가 ≈ $0.13, 편집장 선정 ≈ $0.01, 선정 기사 40여 건 요약 ≈ $0.10 → 회당 약 $0.25. 가격은 바뀔 수 있으니 https://platform.claude.com/docs/en/about-claude/pricing 에서 확인하세요.

## 9. 오류 발생 시 확인할 사항

| 증상 | 확인할 것 |
|---|---|
| `npm start` 가 안 됨 | `node -v` 로 Node.js 20 이상인지 확인. 다른 프로그램이 5173 포트를 쓰면 `PORT=5180 npm start` |
| 휴대폰에서 주소가 안 열림 | PC와 같은 Wi-Fi인지, PC 방화벽이 Node.js 를 막지 않는지. 회사망이면 배포 주소 사용 |
| 화면이 예전 그대로임 | 앱을 완전히 닫았다 다시 열기 (변경분은 다음 실행 때 반영). 그래도 같으면 브라우저 사이트 데이터 삭제 |
| "뉴스 데이터를 불러오지 못했습니다" | 인터넷 연결 확인. 배포 시 Build output directory 가 `public` 인지 확인 |
| 계속 DEMO 표시가 나옴 | 실데이터(`public/data/live/briefing.json`)가 아직 없거나 SETTINGS → 데이터가 `Demo 고정`인지 확인 |
| (Phase 2~) 뉴스가 업데이트 안 됨 | GitHub 저장소 → **Actions** 탭에서 실패한 작업의 빨간 X 클릭 → 로그 확인. 대부분 API Key 누락·오타 |
| (Phase 5~) 알림이 안 옴 | 휴대폰 설정에서 알림 허용 여부, iPhone은 홈 화면 앱으로 실행했는지 |

자동 점검: `npm test`
