# MobiBrief AI

**AI가 골라주는 이번 주 핵심 뉴스.** 자동차보험 · 모빌리티 · 보험 · AI 기술 분야별 TOP 10을 매주 월요일 아침 휴대폰으로 받아 봅니다.

**운영 주소:** https://espoir10517-dotcom.github.io/mobibrief-ai-/  (주소 끝의 `-` 까지 포함)

---

## 한눈에 보는 구조

```
 ┌──── GitHub Actions (무료 자동 실행) ─────┐          ┌──── 휴대폰 ────┐
 │ 매일 06:30   뉴스 수집 (Google News·언론사 RSS) │  JSON   │  MobiBrief AI   │
 │ 월요일 06:30 AI 편집: 평가 → TOP 10 선정 → 요약  │ ──────▶ │  (홈 화면 앱)    │
 │ 월요일 07~22시  각자 정한 시간에 알림 발송      │  파일   │                 │
 └─────────────────────────────────────────┘          └─────────────────┘
```

- **서버·데이터베이스가 없습니다.** 자동 작업이 결과를 JSON 파일로 만들고, 앱은 그 파일을 읽기만 합니다.
- **사용자가 몇 명이든 AI 비용은 같습니다.** AI는 일주일에 한 번만 실행되고, 모든 사람이 같은 결과를 봅니다.
- **사용자 행동은 AI를 부르지 않습니다.** 검색·즐겨찾기·필터는 이미 받은 뉴스 안에서 휴대폰이 직접 처리합니다. 앱 코드에는 AI 키도, AI 호출 코드도 없습니다.
- **API 키는 GitHub 비밀값(Secrets)에만** 저장됩니다. 앱 코드·저장소 파일에는 들어가지 않습니다.
- **즐겨찾기·설정은 각자 휴대폰 안에만** 저장됩니다.
- **기사 전문은 저장하지 않습니다.** 제목·언론사·발행시각·링크·검색 결과 설명문만 쓰고, 원문은 링크로 연결합니다.

### 쓰는 서비스

| 필요한 것 | 선택 | 비용 |
|---|---|---|
| 앱 호스팅 (HTTPS 주소) | GitHub Pages | 무료 |
| 자동 실행 | GitHub Actions (공개 저장소) | 무료 |
| 뉴스 | Google News RSS(한국어) + 국내 언론사 공식 RSS 21곳 | 무료 |
| AI 편집 | Claude API 또는 OpenAI API | 월 약 2천~3천 원 |
| 알림 | Web Push + Cloudflare Workers(구독 목록 보관) | 무료 |

네이버 검색 API는 쓰지 않습니다 (2026년 NAVER API HUB 유료 이관, 9월부터 검색 결과 저장·AI 입력 금지 약관).

## 1. 휴대폰에 설치하기

운영 주소를 휴대폰 브라우저로 연 뒤:

- **iPhone (Safari):** 아래 공유 버튼(□↑) → **홈 화면에 추가**
- **Android (Chrome):** 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**

설치하면 주소창 없이 앱처럼 열리고, 인터넷이 잠깐 끊겨도 마지막 뉴스를 볼 수 있습니다. 새 버전이 올라가면 앱을 열 때 자동으로 바뀝니다.

## 2. 뉴스가 만들어지는 방식

**매일 06:30 (한국시간) — 수집만, 무료**
Google News RSS와 국내 언론사 RSS(연합뉴스·경제지·보험/자동차/AI 전문지)에서 제목·설명문·링크·발행시각을 모아 `data/collected/` 에 쌓습니다. 60일 지난 수집 파일은 자동으로 지웁니다.

**매주 월요일 06:30 — 발행**
1. **정리** — 지난 7일치에서 한국어 기사만 남기고, [포토]/[인사]/[부고]·주가 자동기사를 빼고, 같은 사건 보도를 하나로 묶습니다.
2. **1차 후보** — 키워드 사전(`config/keywords.json`)으로 분야별 후보를 추립니다 (AI 비용을 일정하게 유지하기 위한 단계).
3. **AI 평가** — 후보 전부를 편집 기준(`config/editorial.md`: 손해보험사 자동차보험 부서 관점)으로 읽고 필요 없는 기사를 걸러낸 뒤 5개 기준(중요도·업무 연관도·최신성·영향도·참신성)으로 점수를 매깁니다. 가중치는 `config/scoring.json`.
4. **선정** — 분야별 TOP 10 (같은 사건은 하나만), 이번 주 꼭 알아야 할 이슈 3개, 한 줄 브리핑, 핵심 키워드.
5. **요약** — 선정 기사만 3줄 요약·핵심 내용·왜 중요한가·보험 관점·앞으로 볼 것을 작성합니다.
6. **근거 검증** — 기사에 없는 숫자가 들어간 문장은 자동 삭제. 제목만 있는 기사는 '내용 제한' 표시.
7. **발행 전 점검** — 빈 값·깨진 링크·중복이 있으면 배포를 멈춥니다 (`npm run validate`).

**안전장치:** 한 번 실행에 AI 호출 40회·비용 $1 상한. AI 호출이 실패한 주에는 1차 후보 결과로 대신 발행합니다(화면에 'AI 중요도' 대신 '중요도'로 표시). AI 키가 없으면 같은 주에 만든 AI 브리핑은 유지하고, 지난 브리핑은 1차 후보 결과로 새로 발행해 앱이 멈추지 않게 합니다.

**편집 기준 바꾸기:** `config/editorial.md` 를 고치면 다음 발행부터 그 기준으로 고르고 요약합니다.
**검색어·제외 규칙 바꾸기:** `config/sources.json`.
**직접 발행:** 저장소 → **Actions** → '뉴스 수집 및 주간 브리핑' → **Run workflow**.

## 3. AI 키 등록 (자동 AI 편집 켜기)

GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에 **둘 중 하나**를 등록합니다. 다음 월요일부터 자동으로 AI가 편집합니다.

| 이름 | 어디서 발급 | 기본 모델 |
|---|---|---|
| `ANTHROPIC_API_KEY` | https://platform.claude.com → 결제수단 등록 → API Keys | Claude Haiku 4.5 |
| `OPENAI_API_KEY` | https://platform.openai.com → API keys | gpt-5.4-mini |

- Claude·ChatGPT **구독과 API는 결제가 따로**입니다. API 크레딧은 콘솔 웹사이트에서 충전합니다 (앱스토어 결제 불가).
- 키 값은 채팅·메신저·코드에 붙여 넣지 마세요. 비밀값 화면에만 넣습니다.
- 콘솔에서 **월 사용 한도(spend limit)** 를 $5 정도로 걸어 두면 안심입니다.
- 사용량은 `public/data/live/briefing.json` 의 `ai` 항목과 Actions 실행 기록에 남습니다.

## 4. 알림 설정

**구조:** 알림을 켠 휴대폰의 '알림 받을 주소'와 받을 시간만 Cloudflare(무료)에 저장하고, 매주 월요일 '주간 알림 발송' 작업이 각자 정한 시간에 1번 보냅니다. 이름·연락처는 받지 않습니다.

**처음 연결하기 (관리자 1회):**
1. https://dash.cloudflare.com/sign-up 가입 (무료, 카드 불필요) → 왼쪽 메뉴 **Workers & Pages** 를 한 번 열기
2. 첫 화면 오른쪽의 **Account ID** 복사 → GitHub 비밀값 `CLOUDFLARE_ACCOUNT_ID` 로 등록
3. 오른쪽 위 프로필 → **My Profile → API Tokens → Create Token → Edit Cloudflare Workers** 템플릿 → 만들기 → 토큰을 비밀값 `CLOUDFLARE_API_TOKEN` 으로 등록
4. GitHub **Actions → 알림 서버 배포 → Run workflow** → 초록 체크가 뜨면 끝 (1~2분 뒤 앱에 반영)

**사용자 안내:**
- SETTINGS → **주간 브리핑 알림** 켜기 → 알림 허용 → **받을 시간**(월요일 오전 7시~오후 10시) 선택 → **시험 알림 보내기**로 확인
- 서버 연결 전에 알림을 켜 둔 사람은 연결 후 앱을 열면 자동으로 등록됩니다.
- **Android:** Chrome에서 바로 됩니다 (홈 화면 설치 권장).
- **iPhone:** iOS 16.4 이상, **홈 화면에 추가한 앱**에서 켜야 받습니다 (Safari 탭에서는 불가 — 애플 정책).
- 새 브리핑이 없는 주에는 보내지 않고, 같은 브리핑은 한 번만 보냅니다. GitHub 사정으로 몇 분~수십 분 늦을 수 있습니다.

## 5. 관리자 모드 (MY NEWS 탭)

일반 사용자에게는 HOME · CATEGORY · SAVED · SETTINGS 4개 탭만 보이고, **MY NEWS**(관심 키워드 뉴스)는 관리자에게만 보입니다.

- **켜기:** SETTINGS → 맨 아래 `MobiBrief AI · v0.5` 글자를 **5번 연속** 누름 → 관리자 코드 입력
- **끄기:** SETTINGS → 관리자 → '관리자 모드 끄기'
- 휴대폰·브라우저마다 따로 기억합니다. iPhone은 Safari와 홈 화면 앱이 따로라서 **홈 화면 앱에서 한 번 더** 켜야 합니다.
- 메뉴를 숨기는 기능이며 보안 장치는 아닙니다 (MY NEWS 내용도 모두 공개 뉴스).
- **코드 바꾸기:** `node -e "console.log(require('crypto').createHash('sha256').update('mobibrief:새코드').digest('hex'))"` 실행 → 결과를 `public/js/admin.js` 의 `ADMIN_HASH` 에 넣고 배포 (저장소에는 코드가 아니라 해시값만 저장).

## 7. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 화면이 예전 그대로 | 앱을 완전히 닫고 다시 열기. 그래도 같으면 브라우저 사이트 데이터 삭제 |
| "이번 주 브리핑을 준비하고 있어요" 표시 | 월요일 발행이 실패했거나 아직 안 된 상태. Actions 탭에서 빨간 X 확인 |
| 뉴스가 업데이트 안 됨 | 저장소 → **Actions** → 실패한 작업(빨간 X) → 로그. 대부분 키 누락·잔액 부족. 실패하면 GitHub가 가입 이메일로 알려줍니다 |
| 알림이 안 옴 | 휴대폰 설정에서 이 앱의 알림 허용 여부, iPhone은 홈 화면 앱인지, SETTINGS의 시험 알림 결과 |
| 알림 항목에 '알림 연결 준비 중이에요' 표시 | 4번 '처음 연결하기'가 아직 안 된 상태 |

## 개발자용

**PC에서 실행:** Node.js 20 이상 → `npm start` → http://localhost:5173 (추가 설치 패키지 없음)

| 명령 | 하는 일 |
|---|---|
| `npm test` | 전체 자동 점검 (화면 데이터·수집·AI 편집·알림 암호화·알림 서버) |
| `npm run validate` | 발행 데이터 점검 (발행 전 자동 실행) |
| `npm run collect` | 지금 바로 뉴스 수집 |
| `npm run build:briefing` | 주간 브리핑 만들기 (키가 `.env` 에 있으면 AI 편집) |
| `npm run backfill` | 지난 7일치 기사 채우기 |

```
mobibrief-ai-/
├─ config/        editorial.md(편집 기준) · scoring.json(가중치·TOP N) · sources.json(검색어·RSS) · keywords.json · ai.json
├─ pipeline/      수집 · 중복 묶기 · 1차 점수 · 주간 브리핑 · ai/(AI 편집) · push/(웹 푸시)
├─ worker/        알림 서버 (Cloudflare Worker)
├─ scripts/       실행·점검·배포·알림 발송 스크립트
├─ public/        휴대폰 앱 (이 폴더가 그대로 배포됨) · data/live/(발행 데이터)
├─ data/collected 날짜별 수집 결과 (60일 보관)
└─ .github/workflows  뉴스 수집 및 주간 브리핑 · 알림 서버 배포 · 주간 알림 발송
```

참고: Google News RSS는 개인·비상업적 이용을 전제로 제공됩니다. 이 앱은 제목·언론사·링크만 보여주고 원문으로 연결합니다. 사내 공식 서비스로 확대할 때는 언론사 RSS 위주로 바꾸거나 뉴스 API 계약을 검토하세요.
